### 2. ضبط أشرطة التمرير وقواعد الأرقام (`admin_screen.dart`)
* **دقة التدريج (Steps):**
  * شريط المشاريع الشهرية (`5–100`، خطوة `5`): حسابياً `divisions: 19` لأن `(100 - 5) ~/ 5 = 19`، مع فرض التقريب لأقرب مضاعف لـ 5 في الـ setter تحسّباً لأي استدعاء برمجي.
  * شريط حد الرصيد بالدولار (`5–200`): الطلب لم يقيّده بخطوة 5، لذا برأيي يا **المهندس** و**العملي** إما `divisions: 39` (خطوة `$5` لسهولة السحب باللمس على شاشة الجوال الضيقة) أو `divisions: 195` (خطوة `$1` التزاماً حرفياً بالمدى الكامل `5–200` دون حجب قيم بينية). أميل إلى `divisions: 195` (`1$` لكل خطوة) لعدم فرض قيد غير مذكور في المتطلبات، مع بقاء القيم الابتدائية مضاعفات نظيفة.
* **هوية الأشرطة والأرقام:** وفق جدول الألوان في المرجع، مسار الشريط النشط يأخذ `AppColors.gold500` («تعبئة الأشرطة — ليس للنص»)، والمسار غير النشط `c.track`، أما القيمة الرقمية الظاهرة بجانب العنوان فتُعرض بـ `latinFigures(AppTypography.bodyStrong)` بلون `c.goldText` أو `c.ink` داخل `Directionality(textDirection: TextDirection.ltr)`.
* **تنبيه اتجاه الأرقام:** كل مؤشر رقمي في الشاشة (عداد المشاريع، حد الدولار، `ID` ذو الـ 8 خانات، واستهلاك المستخدم `$`) يجب عزله داخل `Directionality(textDirection: TextDirection.ltr)` مع `latinFigures` كما في `account_screen.dart`.

**اعتراضاتي والبديل لكل منها:**

1. **المهندس:** `Navigator.push` قد يخرج عن `AppStateScope` إذا كان النطاق تحت الـ`home`، فيفشل `AppStateScope.of` بالـassert. البديل: لفّ المسار بنفس نسخة الحالة من السياق الأصلي، بلا لمس `app.dart`:

```dart
  builder: (_) => AppStateScope(state: state, child: const AdminScreen()),

```
والشاشة المدفوعة تحتاج `Scaffold` وخلفية `context.colors.bg` و`SafeArea`؛ `AccountScreen` وحدها لا تملك ذلك.

2. **المحلل:** حد الرصيد إن خُزّن دولاراً عشرياً سيختلط بسنتات `formatUsd` و`CreditBalance`. البديل: الحقل `creditLimitCents` فقط، والشريط يعرض `formatUsd` داخل `Directionality` LTR. الخطوة غير مذكورة؛ أقترح 5 حتى 200 بخطوة 5 (39 قسماً). المشاريع 5–100 بخطوة 5 (19 قسماً). الـsetter يقصّ القيمة ويثبّتها على الخطوة ولا يستدعي `notifyListeners` إن لم يتغيّر العدد، وإلا أعاد شريط التمرير بناء التطبيق كله مع كل حركة.

3. **المدقق:** لا نكتب حدود الباقات داخل `Plan.quotaText` ولا نمس رصيد `$7.40 / $2.60 / $10`. الشرائح حالة إدارية فقط في هذه الدفعة، والحساب سيبقى يعرض «حتى ٢٠» حتى لو حرّكنا العادية. هذا انفصال مقبول لأن `Plan` غير قابل للتعديل، لا عطلاً صامتاً. الافتراضي: العادية 20 مشروعاً (من المرجع)، والباقي قيمة نموذجية لا تُنسخ إلى نص الباقة؛ حد الرصيد الابتدائي `$10` للثلاث حتى لا نخترع تسعيرة. المفتاح هو `plan.id` من `MockData.plans` لا اسم مثبت.

* **التسمية والـ Pill:** أوافق **المهندس** و**العملي** على التسميات الترتيبية المحايدة («المزوّد الأول» … «المزوّد الرابع»)، وعلى الاستغناء عن `StatusChip` غير المرفق وبناء شارة محلية (`_StatePill`) بالألوان الموثّقة في المرجع والمرفقات (`surfaceSoft` + `goldLine` + `goldText` مقابل `track` + `inkMuted`).

### 4. حسم التفاصيل المتبقية
* **`models.dart` واسم التطبيق:** أتفق مع **المتحدّي** و**العملي** على الاكتفاء بإضافة `PlanLimits` و`AdminUser` فقط في `models.dart` التزاماً حرفياً بالطلب، وتمثيل `appName` كـ `String` في `AppState` بقيمة ابتدائية `'بنتارا'` وsetter لا يقبل سوى `'بنتارا'` أو `'Pentara AI'`.

## الحل الصحيح

### 1) الدولار والسنتات (`app_state.dart`)

```dart
void setPlanCreditLimitUsd(String planId, num raw) {
  final cur = _planLimits[planId];
  if (cur == null) return;                       // معرّف مجهول: لا أثر
  final snapped = (raw / PlanLimits.creditStepUsd).round() *
      PlanLimits.creditStepUsd;                  // round() صريح ثم تثبيت الخطوة
  final lo = creditFloorUsd(planId);
  final usd = snapped.clamp(lo, PlanLimits.maxCreditUsd).toInt();
  final cents = usd * 100;
  if (cents == cur.creditLimitCents) return;     // بلا notifyListeners
  _planLimits[planId] = cur.copyWith(creditLimitCents: cents);
  notifyListeners();
}
```

مشاريع الباقة تمر بالمسار نفسه: `round` ثم تثبيت على مضاعف 5 ثم `clamp(5, 100)` ثم المقارنة قبل النبض.

### 2) الشريطان

الاشتقاق من الثوابت في `PlanLimits`:

```dart
static const projectDivisions = (maxProjects - minProjects) ~/ projectStep;       // 19
```

### الخطأ السابق والتصحيح

1. **تحويل الرصيد:** عبارة «نضرب في ١٠٠» لم تكن عقداً تنفيذياً كافياً. في معالج المنزلق نمرّر `value.round() * 100`، وفي setter نثبت القيمة على خطوة **٥٠٠ سنت**، نتحقق من المدى، ثم نقارن بالقيمة الحالية قبل `notifyListeners`. المعرف المجهول يُتجاهل بلا إشعار.

2. **اتجاه المنزلق:** LTR قرار مقصود، وليس نتيجة لازمة لاستخدام الأرقام الغربية. نُبقي العناوين RTL والمنزلق وحده LTR، ونضيف توضيحاً مرئياً مختصراً: **«تزداد قيم المنزلقات نحو اليمين»**، مع قيمتي الطرفين. وتُشتق `divisions` من الثوابت.

3. **البذر:** الاعتماد على ثلاثة عناصر دون فحص كان خطأ. نمرّ على الباقات الموجودة فعلاً، ونستخدم بذور **٢٠/٥٠/١٠٠** حسب الموضع مع قيمة آمنة لأي عنصر زائد، دون إنشاء باقات وهمية. هذه **افتراضات تجريبية بالترتيب** وليست حدوداً مستخرجة من سعر الباقة.
   - القائمة الفارغة: رسالة «لا توجد باقات متاحة» بدل المنزلقات.

   - إنشاء المستخدمين الثلاثة لا يستخدم وصولاً غير محمي مثل `plans[2]`.

### إضافة مهمة على حماية الاستهلاك

أوافق **المهندس** على حساب الحد الأدنى من أعلى استهلاك في الباقة، **بما يشمل المستخدم الموقوف**. ويُرفع هذا الحد إلى مضاعف ٥ دولارات:

لكن **لا نغيّر `Slider.min` وحده مع إبقاء ٣٩ قسماً**؛ فهذا يغيّر حجم الخطوة. الأبسط إبقاء الشريط **٥–٢٠٠ و٣٩ قسماً**، وتقييد القيمة في setter، مع نص عند الحاجة: **«الحد الأدنى لهذه الباقة $… بسبب الاستهلاك المسجّل»**. يُطبَّق القيد عند البذر أيضاً، حتى لا تبدأ الحالة متناقضة.

- **حماية المالك في setter والواجهة:** تعطيل المفتاح وحده لا يمنع الاستدعاء البرمجي.
- **تمرير نسخة الحالة نفسها للمسار:** يضمن وصول الشاشة إلى الـnotifier نفسه. أما وراثة `context.colors` فلا نزعم التحقق منها دون ملف تعريفها؛ نفحص فتح اللوحة في الوضعين وتغيير المظهر ثم إعادة فتحها.

### المتحدّي · Grok (x-ai/grok-4.7)

رئيس الجلسة، أقبل النقض. الإجماع السابق كان اتفاقاً على عقد ناقص، لا دليلاً على صحته. طبّقت الخطوات السبع، وبقي أربعة أفخاخ لم تُغلق.

**1) السنتات: التقريب وحده لا يكفي، والرفض الصامت هو العطل.**
`(value).round() * 100` يمنع `999.999`، لكنه قد يعطي `1200` سنتاً إن انحرفت القيمة عن خطوة 5، فيرفضها التحقق وتُبتلع الحركة. التحقق يعني تثبيتاً ثم قصّاً، لا تجاهلاً. والسنتات عدد صحيح بعد التثبيت، لا `double * 100`:

**2) الاتجاه يُعلن، وعلامتا الطرف في الاتجاه نفسه.**
أوافق على إبقاء المنزلق وحده `LTR` كقرار مقصود، مع سطر ظاهر: «تزداد قيم المنزلقات نحو اليمين». التعليق في الكود لا يكفي. إن وُضع «5» و«200» في صف RTL ظهر الأدنى يميناً بينما أدنى الشريط يساراً. صف العلامتين يُلف مع الشريط. `divisions` من الثوابت: `(max - min) ~/ step`، فالرصيد 39 والمشاريع 19. الخطوة 5 قرار لمس، وأقتنع هنا بحساب **المحلل**؛ لا أعود إلى دولار واحد.

**3) لا باقات وهمية، ولا ثقة بالموضع.**
إن كانت `MockData.plans` فارغة أو أقصر من 3 فلا نرمي ولا نصطنع معرّفات. نبذر الموجود فقط: مطابقة الاسم («العادية»، «ماكس»، «العليا») إن وُجد، وإلا بذرة الموضع `20/50/100` مع سطر أن الترتيب غير مُتحقَّق. الزائد عن البذرة يأخذ 100 لا وصولاً خارج المدى. `currentPlanId` يُنسخ كما هو؛ غيابه يُعرض «باقة غير معروفة»، ولا يُلصَق بأول باقة.

**4) الأرضية في البذر لا في الوثيقة.**
أقتنع بـ**العملي**: لا نغيّر `Slider.min` مع إبقاء 39 قسماً، فذلك يكسر الخطوة. الشريط يبقى 5–200. الأرضية = أعلى استهلاك في الباقة، بما فيه الموقوف، مرفوعاً إلى مضاعف 500 سنت، ثم `max(500, …)`. تُطبَّق عند البذر أيضاً: حد ابتدائي `$10` تحت استهلاك مقروء من `MockData.account` تناقض منذ الفتح، لا بعد السحب. البيانات المزروعة للثلاثة: 120 و420 و0، تحت 500، لكن الكود لا يعتمد على ذلك. إن تجاوزت الأرضية `$200` نعطّل شريط تلك الباقة ونذكر السبب، ولا نخزّن قيمة خارج المدى. المالك يُقرأ من الحساب، لا من `260` ولا من «عبدالله».

**5) المالك.**
`assert` لا يحمي في release. `setUserActive` يرجع بلا نبض إن كان `id == ownerUserId && !value`، أو كان المعرّف مجهولاً، أو كانت القيمة مطابقة. الواجهة: `onChanged: null`. هذا حجب نموذج محلي، لا تفويض.

**6) المسار والرسم.**
لفّ المسار بنسخة `AppStateScope.read` نفسها، وفحص `isOwner` داخل الشاشة: سهم ونص قصير بلا منزلقات. الأيقونة والسهم `CustomPainter` وهدف 44، والسهم يتبع `Directionality`. لا أدّعي أن `context.colors` مُتحقَّق منه؛ الملف غير مرفق. إن كان الامتداد على `Theme` فالمسار تحت `MaterialApp` يرثه، وإن كان موروثاً آخر فقد يفشل. هذا افتراض يُفحص في الوضعين، لا حقيقة. سطوع الشارة من `Theme.of(context).brightness` مع سداسيات جدول المرجع: ok لـ«متصل» وneutral لـ«غير مضبوط»، لا ذهب ولا `StatusChip`. صفّان فقط، كما قلتَ إن العدد ليس الخطأ.

**7) الإعلان في البطاقة لا في الخاتمة.**
«حدود تجريبية لهذه الجلسة؛ لا تغيّر رصيد الحساب ولا نصوص الباقات.» و«حالات المزوّدين عرض فقط؛ لا مفاتيح ولا اتصال.»

ما بقي صحيحاً بالدليل: `appName` مطلوب بنص الدفعة، والمستخدمون في `AppState` كذلك، و`ownerUserId` ثابت في `models.dart`، و`AppStateScope.of` يرمي إن غاب النطاق. لا مسّ لـ`quotaText` ولا لرصيد الحساب.

## ما الخطأ في الحل السابق

1. **التقريب الصامت:** اتفقنا على `value*100` بلا `round()` صريح. `Slider` يمرّر `double`، وقيمة مثل `14.999999999999998` تضرب في 100 فتصير `1499.999…` وبعد `toInt()` تصير `1499` — والتحقق على مضاعفات 500 يرفضها بصمت، فتُبتلع حركة المستخدم. لم يكن في العقد أي ذكر للتقريب ثم التثبيت، فالاتفاق كان سيُنتج كوداً يعمل بالصدفة مع بعض القيم ويفشل مع غيرها.
2. **`Directionality(ltr)` بدون إعلان:** كنّا سنلتف الشريط لعكس اتجاه القراءة العربي دون أن يعرف المستخدم لماذا يزداد المؤشر نحو اليمين. التعليق في الكود لا يصل للمستخدم. هذا قرار تصميم يجب أن يُعلن في الواجهة.
3. **بذر `MockData.plans` بالفهرس بلا حماية:** افترضنا ثلاث باقات بترتيب عادية/ماكس/العليا، وافترضنا وجود `currentPlanId`. أي انحراف في `MockData` يُنتج حدوداً منسوبة لغير باقتها أو يرمي عند الوصول خارج المدى. البذر السليم يتحقق من الطول والترتيب ويحمي القيم الزائدة.
4. **«مستهلكات تحت 500» آمنة بالصدفة لا بالكود:** لم يكن في العقد أي إجراء يمنع حداً أدنى يقل عن أعلى استهلاك في الباقة. لو تغيّر `MockData.account.consumedCents` إلى `800` لسحب المستخدم الشريط إلى `$5` وأنتج تناقضاً محاسبياً. الاتفاق لم يفرض حساب الأرضية ولا تطبيقه عند البذر والكتابة معاً.
5. **الإعلان في «الخطوات التالية» لا في الشاشة:** فصلنا حدود الباقات عن أثرها، ووضعنا هذا التوضيح خارج الواجهة. المستخدم سيرى تعديلات لا تنعكس على الحساب أو نصوص الباقات دون أن يعرف السبب من داخل الشاشة نفسها. النص يجب أن يكون في بطاقة «حدود الباقات» ذاتها.
6. **الذهب لحالة «متصل»:** الذهب في هذا النظام للتمييز التجاري (النقاط، الباقة العليا، حدود ذهبية)، لا لحالة التشغيل. شارة «متصل» يجب أن تأخذ نغمة `ok` الخضراء من جدول المرجع، و«غير مضبوط» نغمة `neutral`.
7. **الادعاء بأن `context.colors` آمنة دون تحقق:** لا نعرف تعريف `context.colors`؛ إن كان امتداداً على `Theme` فسليم، وإن كان عبر `InheritedWidget` خارج `MaterialApp` فقد يفشل في المسار المدفوع. لا نزعم صحته بل نجعله بند فحص في الوضعين.

## الحل الصحيح بعد تطبيق الطريقة

### 1. التقريب والتثبيت
- معالج `Slider` يمرّر `value.round()` كعدد صحيح.
- الـsetter يأخذ `num` ويحوّله إلى `int` أولاً، ثم يثبّت على خطوة 5 دولارات:
  ```dart
  final dollars = raw.round();
  final snappedUsd = ((dollars - 5) ~/ 5 * 5) + 5;
  final loCents = _creditFloorCents(planId);
  final usd = snappedUsd.clamp(loCents ~/ 100, 200);
  final cents = usd * 100;
  ```
- المقارنة قبل `notifyListeners`. معرّف مجهول أو قيمة مطابقة: خروج بلا نبض ولا رمي.

### 2. المنزلقان والاتجاه
- اشتقاق `divisions` من الثوابت: `(max - min) ~/ step` → `19` للمشاريع و`39` للرصيد.
- `Slider` وحده داخل `Directionality(ltr)`، مع سطر أعلى البطاقة: **«تزداد قيم المنزلقات نحو اليمين»**، وعلامتا الطرفين (`5` و`100`، و`$5` و`$200`) داخل نفس التفاف LTR حتى لا يظهر الأدنى في الطرف الخاطئ من وجهة نظر المستخدم العربي. العنوان والتسميات يبقيان RTL.

### 3. البذر المحمي
- نمرّ على `MockData.plans` بطولها الفعلي. إن كانت فارغة: نص «لا توجد باقات متاحة» بدل أمصفوفة فارغة.
- البذور حسب الموضع: `[20, 50, 100]`، وأي عنصر زائد عن الثلاث يأخذ `100` الآمنة.
- `currentPlanId` يُنسخ كما هو. غيابه عن المفاتيح يُعرض «باقة غير معروفة» دون إلصاقه بأول باقة ولا رمي.

### 4. أرضية الاستهلاك
أوافق **العملي** و**المحلل**: لا نغيّر `Slider.min` مع بقاء `39` قسماً، فذلك يكسر الخطوة. الأرضية تُحسب من أعلى استهلاك في الباقة مع رفعها لأعلى مضاعف 500 سنت، وأدناها 500 سنت، وتُطبَّق **مرتين**: عند البذر وعند الكتابة. إن تجاوزت الأرضية `$200` يُعطَّل الشريط لهذه الباقة مع السبب.
- بيانات المالك تُقرأ من `MockData.account.consumedCents` لا من قيمة مثبتة.

### 5. حماية المالك
- `setUserActive` يرجع بلا نبض إن كان `id == ownerUserId && !value`، أو كان المعرّف مجهولاً، أو كانت القيمة مطابقة.
- الواجهة: مفتاح المالك `onChanged: null` مع علامة بصرية لا يمكن إيقافها.
- داخل `AdminScreen`: فحص `isOwner`، وبديل قصير بلا منزلقات إذا لم يكن مالكاً.
- `assert` في `AdminUser` كمستند فقط، لا كحماية في release.

### 6. المسار والرسم
- من `AccountScreen`: `final app = AppStateScope.of(context)` ثم لفّ المسار بنسخة الحالة نفسها:
  ```dart
  Navigator.of(context).push(MaterialPageRoute<void>(
    builder: (_) => AppStateScope(state: app, child: const AdminScreen()),
  ));
  ```
  هذا يغلق احتمال غياب النطاق تحت `home` دون ازدواج في الـ`ChangeNotifier`.
- `context.colors` يبقى بند فحص في الوضعين، لا ادعاء سلامة.
- سهم الرجوع وأيقونة الصف `CustomPainter`: السهم يتبع `Directionality`، والأيقونة أشرطة ضبط بثلاثة خطوط بمقابض دائرية، هدف اللمس 44.
- الشارات: `ok` لـ«متصل» و`neutral` لـ«غير مضبوط»، سداسيات جدول المرجع فاتح/داكن، لا ذهب ولا `StatusChip`.

### 7. الإعلان في الواجهة
- في بطاقة «حدود الباقات»: **«إعدادات تجريبية محفوظة خلال جلسة التشغيل فقط؛ لا تغيّر رصيد الحساب أو نصوص الباقات حالياً.»**
- في «مفاتيح النماذج»: **«حالات تجريبية للعرض؛ لا مفاتيح مخزّنة ولا اتصال فعلي.»**

> **الطريقة التي يجب أن يعتمدها الأعضاء:**
> 1. رتّب التهيئة في AppState: ابنِ users أولاً (المالك من MockData.account ثم ثلاثة ثوابت: 120/420/0 سنتاً)، ثم ابذر planLimits مع تطبيق الأرضية على كل باقة.

> 3. ثبّت القيمة بالتقريب لأقرب خطوة: usd = (raw / 5).round() * 5 ثم clamp(floor, 200).toInt()، وللمشاريع (raw / 5).round() * 5 ثم clamp(5, 100)، وقارن بالمخزّن قبل notifyListeners، وتجاهل المعرّف المجهول بلا أثر.
> 4. اشتق divisions من الثوابت (19 و39) واجعل Slider.value دائماً القيمة المخزّنة بعد القصّ؛ إن أبقيت LTR للشريط فلف صف العلامتين معه واذكر الاتجاه بسطر ظاهر، أو الأفضل ترك الشريط يتبع RTL ولف الأرقام فقط بـ LTR.
> 5. تعامل مع باقة المالك المفقودة: اعرض 'باقة غير معروفة' وتجاوز الأرضية لها دون رمي، وابذر الباقات الموجودة فقط بالموضع 20/50/100 وما زاد 100.

> 9. أضف الفحوص: سحب الرصيد دون الأرضية، وأرضية فوق 200، وباقة مفقودة، وقائمة باقات فارغة، وعدم النبض عند التحديث المطابق أو المرفوض.

```dart
String toArabicDigits(String input) {
  const western = '0123456789';
  const eastern = '٠١٢٣٤٥٦٧٨٩';
  final buffer = StringBuffer();
  for (final rune in input.runes) {
    final ch = String.fromCharCode(rune);
    final i = western.indexOf(ch);
    buffer.write(i < 0 ? ch : eastern[i]);
  }
  return buffer.toString();
}

  static List<Round> _buildRounds(List<Message> messages, List<String> titles) {
    final result = <Round>[];
    for (var i = 0; i < titles.length; i++) {
      final number = i + 1;
      final first = messages.indexWhere((m) => m.roundNumber == number);
      if (first < 0) continue;
      var end = first;
      while (end < messages.length && messages[end].roundNumber == number) {
        end++;
      }
      result.add(Round(number: number, title: titles[i], start: first, end: end));
    }
    return List.unmodifiable(result);
```
```dart
  }

class _ArrowPainter extends CustomPainter {
  const _ArrowPainter({required this.pointRight, required this.color});

  final bool pointRight;
  final Color color;

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    canvas.scale(size.width / 24);
    if (!pointRight) {
      canvas.translate(24, 0);
      canvas.scale(-1, 1);
    }
    final p = Paint()
      ..color = color
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2
      ..strokeCap = StrokeCap.round
      ..strokeJoin = StrokeJoin.round
      ..isAntiAlias = true;
    canvas.drawLine(const Offset(5, 12), const Offset(19, 12), p);
    final head = Path()
      ..moveTo(13, 6)
      ..lineTo(19, 12)
      ..lineTo(13, 18);
    canvas.drawPath(head, p);
    canvas.restore();
  }

  @override
  bool shouldRepaint(covariant _ArrowPainter old) =>
      old.pointRight != pointRight || old.color != color;
}

/// معاينة مصغّرة: ست نقاط، الرئيس مميّز بالذهبي (يمين الصف، وأعلى الطاولة).
class _LayoutPreviewPainter extends CustomPainter {
  const _LayoutPreviewPainter({
    required this.layout,
    required this.dot,
    required this.accent,
    required this.ring,
  });

  final MembersLayout layout;
  final Color dot;
  final Color accent;
  final Color ring;

  // متجهات الوحدة كل 60° بدءاً من الأعلى مع عقارب الساعة (دون استيراد math).
  static const List<Offset> _unit = [
    Offset(0, -1),
    Offset(0.8660254, -0.5),
    Offset(0.8660254, 0.5),
    Offset(0, 1),
    Offset(-0.8660254, 0.5),
    Offset(-0.8660254, -0.5),
  ];

  @override
  void paint(Canvas canvas, Size size) {
    final w = size.width;
    final h = size.height;
    final points = <Offset>[];

    switch (layout) {
      case MembersLayout.row:
        {
          const pad = 14.0;
          final gap = (w - 2 * pad) / 5;
          for (var i = 0; i < 6; i++) {
            points.add(Offset(w - pad - i * gap, h / 2));
          }
        }
      case MembersLayout.grid4:
        {
          const pad = 18.0;
          final gap = (w - 2 * pad) / 3;
          for (var i = 0; i < 4; i++) {
            points.add(Offset(w - pad - i * gap, h * 0.3));
          }
          points.add(Offset(w / 2 + gap / 2, h * 0.74));
          points.add(Offset(w / 2 - gap / 2, h * 0.74));
        }
      case MembersLayout.table:
        {
          final center = Offset(w / 2, h / 2);
          final r = h / 2 - 7;
          canvas.drawCircle(
            center,
            r,
            Paint()
              ..color = ring
              ..style = PaintingStyle.stroke
              ..strokeWidth = 1.5
              ..isAntiAlias = true,
          );
          for (final u in _unit) {
            points.add(center + u * r);
          }
        }
    }

    for (var i = 0; i < points.length; i++) {
      final chair = i == 0;
      canvas.drawCircle(
        points[i],
        chair ? 5.5 : 4.5,
        Paint()
          ..color = chair ? accent : dot
          ..style = PaintingStyle.fill
          ..isAntiAlias = true,
      );
    }
  }

  @override
  bool shouldRepaint(covariant _LayoutPreviewPainter old) =>
      old.layout != layout ||
      old.dot != dot ||
      old.accent != accent ||
      old.ring != ring;
}
```

```dart
/// يحوّل الأرقام الغربية إلى العربية (٠–٩). للتواريخ والسرد فقط،
/// لا للأسعار ولا للمؤشرات (تبقى غربية داخل Directionality LTR).
String toArabicDigits(String input) {
  const western = '0123456789';
  const eastern = '٠١٢٣٤٥٦٧٨٩';
  final buffer = StringBuffer();
  for (final rune in input.runes) {
    final ch = String.fromCharCode(rune);
    final i = western.indexOf(ch);
    buffer.write(i < 0 ? ch : eastern[i]);
  }
  return buffer.toString();
}

/// سنتات الدولار بأعداد صحيحة، بلا فاصلة عائمة.
/// 1000 → $10، و740 → $7.40، و42 → $0.42.
String formatUsd(int cents) {
  assert(cents >= 0);
  final whole = cents ~/ 100;
  final rest = cents % 100;
  if (rest == 0) return '\$$whole';
  return '\$$whole.${rest.toString().padLeft(2, '0')}';
}

/// هللات الريال بمنزلتين دائماً: 1860 → 18.60 ر.س.
String formatSar(int halalas) {
  assert(halalas >= 0);
  final whole = halalas ~/ 100;
  final rest = halalas % 100;
  return '$whole.${rest.toString().padLeft(2, '0')} ر.س';
}

/// فاصل آلاف غربي: 1500 → 1,500. (للمؤشرات: أرقام غربية.)
String formatThousands(int value) {
  final s = value.abs().toString();
  final buffer = StringBuffer();
  for (var i = 0; i < s.length; i++) {
    if (i > 0 && (s.length - i) % 3 == 0) buffer.write(',');
    buffer.write(s[i]);
  }
  return value < 0 ? '-$buffer' : buffer.toString();
}

  Discussion({

    required this.messages,
    required List<String> roundTitles,
    required this.summary,
  }) : rounds = _buildRounds(messages, roundTitles);

  final String projectId;
  final List<Message> messages;
  final List<Round> rounds;
  final Summary summary;

  /// المؤشر الافتراضي عند الفتح: نهاية الجولة ١ بلا كشف أي رسالة من ٢.
  int get initialCursor => rounds.isEmpty ? 0 : rounds.first.end;

  static List<Round> _buildRounds(List<Message> messages, List<String> titles) {
    final result = <Round>[];
    for (var i = 0; i < titles.length; i++) {
      final number = i + 1;
      final first = messages.indexWhere((m) => m.roundNumber == number);
      if (first < 0) continue;
      var end = first;
      while (end < messages.length && messages[end].roundNumber == number) {
        end++;
      }
      result.add(Round(number: number, title: titles[i], start: first, end: end));
    }
    return List.unmodifiable(result);
  }
}
```

```dart
    return floorCents ~/ 100;
```

```dart
/// يحوّل الأرقام الغربية إلى العربية (٠–٩). للتواريخ والسرد فقط،
/// لا للأسعار ولا للمؤشرات (تبقى غربية داخل Directionality LTR).
String toArabicDigits(String input) {
  const western = '0123456789';
  const eastern = '٠١٢٣٤٥٦٧٨٩';
  final buffer = StringBuffer();
  for (final rune in input.runes) {
    final ch = String.fromCharCode(rune);
    final i = western.indexOf(ch);
    buffer.write(i < 0 ? ch : eastern[i]);
  }
  return buffer.toString();
}

/// سنتات الدولار بأعداد صحيحة، بلا فاصلة عائمة.
/// 1000 → $10، و740 → $7.40، و42 → $0.42.
String formatUsd(int cents) {
  assert(cents >= 0);
  final whole = cents ~/ 100;
  final rest = cents % 100;
  if (rest == 0) return '\$$whole';
  return '\$$whole.${rest.toString().padLeft(2, '0')}';
}

/// فاصل آلاف غربي: 1500 → 1,500. (للمؤشرات: أرقام غربية.)
String formatThousands(int value) {
  final s = value.abs().toString();
  final buffer = StringBuffer();
  for (var i = 0; i < s.length; i++) {
    if (i > 0 && (s.length - i) % 3 == 0) buffer.write(',');
    buffer.write(s[i]);
  }

}

    for (var i = 0; i < titles.length; i++) {
      final number = i + 1;
      final first = messages.indexWhere((m) => m.roundNumber == number);
      if (first < 0) continue;
      var end = first;
      while (end < messages.length && messages[end].roundNumber == number) {
        end++;
      }
      result.add(Round(number: number, title: titles[i], start: first, end: end));
    }
    return List.unmodifiable(result);
  }
}
```

```dart
class _ArrowPainter extends CustomPainter {
  const _ArrowPainter({required this.color, required this.pointRight});

  final Color color;
  final bool pointRight;

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    canvas.scale(size.width / 24);
    final p = Paint()
      ..color = color
      ..style = PaintingStyle.stroke
      ..strokeWidth = 2
      ..strokeCap = StrokeCap.round
      ..strokeJoin = StrokeJoin.round
      ..isAntiAlias = true;
    final path = Path();
    if (pointRight) {
      path
        ..moveTo(4, 12)
        ..lineTo(20, 12)
        ..moveTo(14, 6)
        ..lineTo(20, 12)
        ..lineTo(14, 18);
    } else {
      path
        ..moveTo(20, 12)
        ..lineTo(4, 12)
        ..moveTo(10, 6)
        ..lineTo(4, 12)
        ..lineTo(10, 18);
    }
    canvas.drawPath(path, p);
    canvas.restore();
  }

  @override
  bool shouldRepaint(covariant _ArrowPainter old) =>
      old.color != color || old.pointRight != pointRight;
}

class _LayoutPreviewPainter extends CustomPainter {
  const _LayoutPreviewPainter({
    required this.layout,
    required this.dot,
    required this.chair,
    required this.ring,
  });

  final MembersLayout layout;
  final Color dot;
  final Color chair;
  final Color ring;

  @override
  void paint(Canvas canvas, Size size) {
    const r = 4.5;
    final paint = Paint()..isAntiAlias = true;

    void drawDot(Offset o, bool isChair) {
      paint.color = isChair ? chair : dot;
      canvas.drawCircle(o, r, paint);
    }

    switch (layout) {
      case MembersLayout.row:
        final slot = size.width / 6;
        for (var i = 0; i < 6; i++) {
          drawDot(Offset(size.width - slot * (i + 0.5), size.height / 2), i == 0);
        }
      case MembersLayout.grid4:
        final slot = size.width / 4;
        for (var i = 0; i < 4; i++) {
          drawDot(Offset(size.width - slot * (i + 0.5), size.height * 0.3), i == 0);
        }
        drawDot(Offset(size.width / 2 + slot / 2, size.height * 0.72), false);
        drawDot(Offset(size.width / 2 - slot / 2, size.height * 0.72), false);
      case MembersLayout.table:
        final center = Offset(size.width / 2, size.height / 2);
        final radius = math.min(size.width, size.height) / 2 - r - 2;
        final stroke = Paint()
          ..color = ring
          ..style = PaintingStyle.stroke
          ..strokeWidth = 1
          ..isAntiAlias = true;
        canvas.drawCircle(center, radius, stroke);
        for (var i = 0; i < 6; i++) {
          final a = -math.pi / 2 + i * math.pi / 3;
          drawDot(
            Offset(center.dx + radius * math.cos(a),
                center.dy + radius * math.sin(a)),
            i == 0,
          );
        }
    }
  }

  @override
  bool shouldRepaint(covariant _LayoutPreviewPainter old) =>
      old.layout != layout ||
      old.dot != dot ||
      old.chair != chair ||
      old.ring != ring;
```

/// في الوضع الداكن تظهر الشمس (للعودة للفاتح)، وفي الفاتح القمر.
class _ThemeIconPainter extends CustomPainter {
  const _ThemeIconPainter({required this.isDark, required this.color});

  final bool isDark;
  final Color color;

  @override
  void paint(Canvas canvas, Size size) {
    canvas.save();
    canvas.scale(size.width / 24);
    final fill = Paint()
      ..color = color
      ..style = PaintingStyle.fill
      ..isAntiAlias = true;
    if (isDark) {
      canvas.drawCircle(const Offset(12, 12), 4.5, fill);
      final line = Paint()
        ..color = color
        ..style = PaintingStyle.stroke
        ..strokeWidth = 2
        ..strokeCap = StrokeCap.round
        ..isAntiAlias = true;
      for (var i = 0; i < 8; i++) {
        final a = i * 3.141592653589793 / 4;
        final dx = _cos(a);
        final dy = _sin(a);
        canvas.drawLine(
          Offset(12 + 7.5 * dx, 12 + 7.5 * dy),
          Offset(12 + 10 * dx, 12 + 10 * dy),
          line,
        );
      }
    } else {
      final moon = Path()
        ..addOval(Rect.fromCircle(center: const Offset(12, 12), radius: 8.5));
      final cut = Path()
        ..addOval(Rect.fromCircle(center: const Offset(16, 9), radius: 7));
      canvas.drawPath(
        Path.combine(PathOperation.difference, moon, cut),
        fill,
      );
    }
    canvas.restore();
  }

  static double _cos(double a) => _approx(a, true);
  static double _sin(double a) => _approx(a, false);

  static double _approx(double a, bool isCos) {
    // قيم مضبوطة للزوايا مضاعفات π/4 المستعملة فقط.
    const r = 0.7071067811865476;
    final k = (a / (3.141592653589793 / 4)).round() % 8;
    const cosT = [1.0, r, 0.0, -r, -1.0, -r, 0.0, r];
    const sinT = [0.0, r, 1.0, r, 0.0, -r, -1.0, -r];
    return isCos ? cosT[k] : sinT[k];
  }

  @override
  bool shouldRepaint(covariant _ThemeIconPainter old) =>
      old.isDark != isDark || old.color != color;
}
